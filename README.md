# privacy-policies

Políticas de privacidad públicas (HTML) servidas con **GitHub Pages**.

Play Store y las apps enlazan a estas URLs HTTPS, no a ficheros `.md` del editor de GitHub.

## Sitio

- Índice: https://jorgearellanosubias.github.io/privacy-policies/
- Tus Pasitos: https://jorgearellanosubias.github.io/privacy-policies/tus-pasitos/

## Añadir otra app

1. Crea `nombre-app/index.html` con la política (español, HTML estático).
2. Enlázala desde `index.html`.
3. Haz push a `main`; Pages publica la raíz del branch.

## Nota

El usuario de GitHub Pages es el slug en minúsculas del propietario:
`https://<owner>.github.io/<repo>/…`
